# Mesh_Network_Project

# 🌐 Mesh Network & Off-Grid Messenger Project

အင်တာနက်လိုင်း သို့မဟုတ် မိုဘိုင်းဆယ်လူလာလိုင်းများ လုံးဝမရရှိတော့သည့် အခြေအနေများ (Internet Blackout / Natural Disasters) တွင် ဒေသတွင်း ဖုန်းများနှင့် စက်ပစ္စည်းများ အချင်းချင်း အင်တာနက်မလိုဘဲ တိုက်ရိုက်ချိတ်ဆက်ကာ အရေးပေါ် သတင်းအချက်အလက်နှင့် ကူညီကယ်ဆယ်ရေးများကို အချိန်နှင့်တပြေးညီ လုပ်ဆောင်နိုင်ရန် တည်ဆောက်ထားသော Off-Grid Mesh Messenger နှင့် Flood/Emergency Alert Dashboard စနစ် ဖြစ်ပါသည်။

---

## 🚀 Key Features (အဓိက လုပ်ဆောင်ချက်များ)

* **📶 Off-Grid Local Mesh Communication:** အင်တာနက်လိုင်း မလိုအပ်ဘဲ Wi-Fi / Hotspot ဖြင့် အနီးအနားရှိ စက်ပစ္စည်းများနှင့် တိုက်ရိုက်ချိတ်ဆက်ပေးခြင်း[cite: 3]။
* **📡 Live Mesh Radar & Peer Tracking:** ပတ်ဝန်းကျင်တွင် ချိတ်ဆက်ထားသော Active Devices များကို ရေဒါမျက်နှာပြင်ပေါ်တွင် အချိန်နှင့်တပြေးညီ ရှာဖွေဖော်ပြပေးခြင်း[cite: 3]။
* **⚠️ Emergency SOS & Multi-Hop Broadcast:** အရေးပေါ် အကူအညီတောင်းခံမှုများ (SOS) နှင့် သတင်းများကို အနီးအနားရှိ ဖုန်းများမှတစ်ဆင့် တဆင့်ပြီးတဆင့် (Multi-hop) ဖြန့်ဝေပေးခြင်း[cite: 3]။
* **🌊 FloodGuard AI Dashboard Integration:** ရေကြီးမှု အန္တရာယ်များကို ကြိုတင်ခန့်မှန်းပေးခြင်း၊ ဒေသအလိုက် ရေအဆင့်အတန်းများကို စောင့်ကြည့်ခြင်းနှင့် ကယ်ဆယ်ရေးတောင်းဆိုမှုများကို Timeline ဖြင့် စီမံခန့်ခွဲခြင်း[cite: 3]။
* **📷 Multimedia Support (Image & Voice Notes):** အရေးပေါ် အခြေအနေများတွင် စာသားများအပြင် ဓာတ်ပုံများနှင့် အသံဖိုင် (Voice Notes) များကိုပါ ပူးတွဲပေးပို့နိုင်ခြင်း[cite: 3]။
* **🛡️ Rescue Responder Integration:** ကယ်ဆယ်ရေးအဖွဲ့များက "ငါတို့လာကူညီနေပြီ" ဟု Status အတိအကျဖြင့် တုံ့ပြန်ဆောင်ရွက်နိုင်ခြင်း[cite: 3]။
* **🌓 Dark / Light Mode Support:** အသုံးပြုသူများ အလွယ်တကူ ပြောင်းလဲအသုံးပြုနိုင်သော Theme Control စနစ်[cite: 3]။

## 📱 How It Works (အလုပ်လုပ်ပုံ အကျဉ်း)

1. **Connect Hotspot:** အင်တာနက်လိုင်း ပျက်တောက်နေချိန်တွင် ဒေသတွင်း ထုတ်လွှင့်ထားသော Mesh Wi-Fi Hotspot သို့ ဖုန်းဖြင့် ချိတ်ဆက်ပါ[cite: 3]။
2. **Device Registration:** Dashboard ထဲသို့ ဝင်ရောက်ပြီး မိမိ၏ Device Name ကို သတ်မှတ်ပါ[cite: 3]။
3. **Radar & Messaging:** အနီးအနားရှိ စက်များကို ရေဒါပေါ်တွင် မြင်တွေ့ရမည်ဖြစ်ပြီး Direct Message များ ပို့ခြင်း၊ SOS အရေးပေါ်အချက်ပြခြင်းများကို အင်တာနက်မလိုဘဲ အသုံးပြုနိုင်မည် ဖြစ်သည်[cite: 3]။
