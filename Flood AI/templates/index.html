How Offline Mesh Network Works

အင်တာနက်လိုင်းလုံးဝမရှိတော့သော အခြေအနေများ (Internet Blackout / Natural Disasters) တွင် ဒေသတွင်း ဖုန်းများနှင့် စက်ပစ္စည်းများ အချင်းချင်း ချိတ်ဆက်နိုင်ရန် တည်ဆောက်ထားသော Local Mesh နည်းပညာ အလုပ်လုပ်ပုံ အသေးစိတ် -

1. Direct Wi-Fi / Hotspot Connection

အနီးအနားရှိ ဖုန်းများ သို့မဟုတ် စာဗာစက်ပစ္စည်း (Server PC) မှ ထုတ်လွှင့်ပေးသော ဒေသတွင်း Wi-Fi (SSID) သို့ ဖုန်းကင်မရာဖြင့် QR Code scan ဖတ်၍ဖြစ်စေ၊ တိုက်ရိုက်ချိတ်ဆက်၍ဖြစ်စေ အင်တာနက်မလိုဘဲ ချိတ်ဆက်နိုင်ပါသည်။

2. Multi-Hop Data Relaying

အရေးပေါ် အကူအညီတောင်းခံမှု (SOS) များနှင့် သတင်းအချက်အလက်များကို အင်တာနက်လိုင်းမလိုဘဲ အနီးအနားရှိ အခြားချိတ်ဆက်ထားသော ဖုန်းများက တဆင့်ပြီးတဆင့် (Hop by Hop) ကူးပြောင်းပေးပို့နိုင်စွမ်း ရှိပါသည်။

3. Immediate Local Alerts

ရေကြီးခြင်း အန္တရာယ် သတိပေးချက်များ၊ အရေးပေါ် အကူအညီတောင်းခံမှုများကို ဒေသတွင်းချိတ်ဆက်ထားသူ အချင်းချင်း ချက်ချင်းသိရှိနိုင်ပြီး ကယ်ဆယ်ရေးလုပ်ငန်းများကို အချိန်နှင့်တပြေးညီ ဆောင်ရွက်နိုင်စေပါသည်။

4. Secure & Decentralized

ပြင်ပဆာဗာများအပေါ် မှီခိုနေစရာမလိုဘဲ Local Network အတွင်းသာ လည်ပတ်သောကြောင့် အချက်အလက်လုံခြုံမှု ရှိပြီး မည်သည့် အရေးပေါ်အခြေအနေမျိုးတွင်မဆို အဆက်အသွယ်မပြတ်စေရန် အကောင်းဆုံး ထောက်ပံ့ပေးပါသည်။
